# AuraScribe — landing page

The marketing website for **[AuraScribe](https://github.com/JeswinJestin/AuraScribe)**, the free,
open-source, 100% offline voice dictation and voice typing app for **Windows, macOS, and Linux**.

## 📖 About

This repository is **only the website** — the AuraScribe app itself lives in a
[separate repo](https://github.com/JeswinJestin/AuraScribe). The site exists to explain what
AuraScribe is (private, local, free voice dictation and voice typing), and to rank for the searches
people actually use: *"free Wispr Flow alternative"*, *"free dictation tool for Windows, Mac and
Linux"*, *"open-source voice typing"*, *"offline dictation"*, and *"on-device Malayalam speech to
text"*.

It is a single-page scrolling story plus a small set of content pages (About, Blog, Privacy, Terms),
built with an editorial **"cream broadsheet / dark velvet chamber"** design that shifts colour as you
scroll. Everything is static and self-hosted — no trackers, no cookies, no third-party scripts.

## ✨ Highlights

- 🎞️ **Scroll-driven narrative** — Lenis smooth scroll + GSAP + Motion, with `prefers-reduced-motion`
  honoured everywhere.
- 🌀 **Auto-cycling language wheel** — showcases the languages AuraScribe handles (English, European,
  Asian, Malayalam, Kannada), each with a live example, on a timer you can click to control.
- 🎨 **Two-typeface editorial system** — EB Garamond display serif + Figtree UI, one indigo accent,
  flat 2px borders, no shadows or gradients.
- 📝 **Blog** — eight SEO long-tail posts (Windows, macOS, Linux, comparisons) with `BlogPosting`
  structured data.
- 🔍 **Production SEO** — canonical URLs, sitemap, robots, Open Graph + Twitter cards, a real
  `next/og` social image, and `SoftwareApplication` / `WebSite` / `FAQPage` / `Person` JSON-LD.
- 🔒 **Hardened** — Content-Security-Policy, HSTS, `X-Content-Type-Options`, `X-Frame-Options`,
  Referrer-Policy, Permissions-Policy; WCAG AA colour contrast in both chambers.
- 📨 **Contact form** — posts to a Google Form, with a `mailto` fallback and no third-party tracker.

## 🧱 Tech stack

Next.js 14 (App Router) · Tailwind CSS 3 · GSAP + ScrollTrigger · Lenis · Motion ·
`@phosphor-icons/react` · deployed on Vercel.

## 🚀 Run locally

```bash
npm install
```

```bash
npm run dev
```

Open http://localhost:3000. Before shipping a change: `npx tsc --noEmit` and `npm run build` must
both be clean.

## ☁️ Deploy

Deployed on Vercel from this repo (auto-deploys on push to `master`). Full launch steps — Vercel
import, DNS at name.com, Google Form, and Search Console — are in
**[docs/LAUNCH.md](docs/LAUNCH.md)**. Canonical/sitemap/OG default to `https://www.aurascribe.dev`
(override with the `NEXT_PUBLIC_SITE_URL` env var).

## ✏️ Editing content

- Copy, keywords, engines, comparison, FAQ, author/socials: [`lib/site.ts`](lib/site.ts)
- Blog posts: [`lib/blog.ts`](lib/blog.ts) (metadata) + `app/blog/<slug>/page.tsx` (body)
- Sections/components: [`components/`](components/)
- Brand tokens (both chambers): [`app/globals.css`](app/globals.css) and
  [`components/theme-scroll.tsx`](components/theme-scroll.tsx)
- **Read [`docs/HANDOFF.md`](docs/HANDOFF.md) first** — it is the source of truth for the design
  system, how the scroll/colour bits work, and the pending-task list.

## 🔎 SEO / structured data

- Metadata, Open Graph, Twitter card, and JSON-LD (`SoftwareApplication` + `WebSite` + `FAQPage` +
  `Person`) live in [`app/layout.tsx`](app/layout.tsx); blog posts add `BlogPosting` + `BreadcrumbList`.
- `sitemap.xml`, `robots.txt`, and the 1200×630 `next/og` social image are generated by
  `app/sitemap.ts`, `app/robots.ts`, and `app/opengraph-image.tsx`.
- Target keywords are in `site.keywords` and woven through the copy (no stuffing).
